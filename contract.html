1. Scope of Work & Comprehensive Deliverables

The Contractor agrees to perform specialized visual system design services for AvalonFlow Corp ("Client"). The specific deliverables under this Agreement include:

  • Icon System & Usage Guide: A comprehensive 4–6 page PDF document defining the core visual design language, geometric rules, rationale behind each icon (Safety, Sync, Compliance, Support), and implementation guidelines (including light/dark mode UI mockups).
  • Master Source Files: Fully editable vector source files in .AI / .EPS formats containing all system grid assets.
  • Production-Ready Assets: Clean, web-optimized .SVG files ready for mobile-responsive dashboard implementation.
  • Final Delivery: All vector assets/.SVG files and documentation packaged into a single compressed .zip file strictly under 50MB in size.

2. Financial Terms & Compensation

Client agrees to pay Contractor a fixed total fee of $3,400.00 USD for all scope items, documentation, source vectors, and deliverables specified in Section 1. Disbursement will be immediately processed 100% upfront directly to your preferred payment method.
